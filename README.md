# EVroute ⚡ – Android sürümleri

Elektrikli araçlar için şarj eğrisine duyarlı rota planlayıcı.
Bu repo yalnızca **Android kurulum dosyalarını (APK)** dağıtmak içindir.

## İndir

👉 **[Son sürümü indir](https://github.com/Mehmet4nil/evroute-remUpdate/releases/latest)**:
"Assets" altındaki `evroute-X.Y.Z.apk` dosyası.

## İlk kurulum

1. APK'yı telefonunuzdan indirin.
2. Açınca Android "bilinmeyen kaynaklardan yükleme" izni ister: tarayıcınıza (veya dosya
   yöneticinize) bir kez izin verin.
3. **Yükle**'ye dokunun.

## Güncellemeler

Yeni bir sürüm yayınlandığında uygulama açılışta **"Güncelle"** penceresi gösterir. Uygulama
APK'yı indirip kurulum ekranını açar; EVroute'a bir kez kurulum izni vermeniz istenebilir.
Sağ üstteki ⟳ simgesiyle elle de kontrol edebilirsiniz.
